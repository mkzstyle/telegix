Telegram Bot API · TypeScript

Build bots with a typed core.

telegix is a small, modular wrapper around the official Telegram Bot API. Send requests, upload files, receive updates, and keep your bot code fully typed as Telegram evolves.

Start buildingView on npm ↗

What is telegix?

telegix exposes the official Bot API through a predictable client while keeping the runtime lightweight. The generated surface is refreshed from Telegram's official documentation, so method names and return types track the upstream API.

Typed API methods

Generated methods mirror Telegram's method catalog and ship with declaration files.

JSON and multipart

Use ordinary objects for JSON requests or InputFile for uploads without changing your bot logic.

Reliable transport

Timeouts, AbortSignal cancellation, retry delays, rate-limit handling, and typed errors are built in.

Update primitives

Long polling, webhook dispatch, secret validation, and key-based routing cover common bot architectures.

Quickstart

Install telegix in a Node.js 18+ project. Keep your bot token in an environment variable; never commit it to source control.

npm install telegix
import { createBot } from 'telegix'

const bot = createBot(process.env.BOT_TOKEN!)
await bot.call('sendMessage', {
  chat_id: 123456789,
  text: 'Hello from telegix'
})
The bot token is only used server-side to call https://api.telegram.org/bot<token>/<method>.

TelegramClient

Use createBot(token, defaults?) for a configured client, or instantiate TelegramClient directly. Every request returns the unwrapped Telegram result when the API response is successful.

const bot = createBot(token, {
  timeout: 10_000, retries: 3, retryDelay: 500
})
const me = await bot.call('getMe')
const send = bot.method('sendMessage')
await send({ chat_id: chatId, text: 'Reusable method' })

Files and uploads

InputFile accepts a Telegram file ID, local path, URL, Uint8Array, Buffer, Readable, or Blob. If any parameter is an InputFile, telegix automatically switches to multipart/form-data.

import { InputFile } from 'telegix'

await bot.call('sendDocument', {
  chat_id: chatId,
  document: InputFile.from('./guide.pdf', 'guide.pdf'),
  caption: 'Documentation'
})

For an existing Telegram file, pass its file ID as a plain string. Use InputFile.from(source, filename?) when you need explicit upload semantics.

Receiving updates

Long polling

poll calls getUpdates, advances the offset, and invokes your handler for each update. Stop it with an AbortController.

const controller = new AbortController()
await poll(bot, async update => {
  console.log(update)
}, { signal: controller.signal, timeout: 30 })

Webhooks

Use dispatchWebhook(request, handler, secret?) inside a standard Web Request handler. When a secret is supplied, telegix checks Telegram's x-telegram-bot-api-secret-token header and returns 401 on failure.

export async function POST(request: Request) {
  return dispatchWebhook(request, update =>
    router.handle(update), process.env.WEBHOOK_SECRET)
}

Router

Router lets you attach handlers to update keys such as message, callback_query, or inline_query. Matching handlers execute in registration order.

const router = new Router()
router.on('message', async update => {
  await bot.call('sendMessage', {
    chat_id: update.message.chat.id, text: 'Got it'
  })
})
router.on('callback_query', update => console.log(update))

Errors, retries, and cancellation

Telegram API failures become TelegramError with errorCode, description, and optional response parameters. Network failures become TelegramNetworkError; timed-out requests become TelegramTimeoutError.

  • HTTP JSON requests use application/json.
  • File requests use FormData and multipart encoding.
  • 429 responses honor Telegram's retry_after value.
  • 429 and 5xx responses use exponential retry backoff.
  • Pass an AbortSignal per request or as a default.
try {
  await bot.call('sendMessage', { chat_id: chatId, text: 'Hi' }, { signal })
} catch (error) {
  if (error instanceof TelegramError)
    console.error(error.errorCode, error.description)
}

Generated API surface

At publish time, the generator reads the official Telegram Bot API page and creates typed declarations for documented methods and object types. Generated files are intentionally not committed to the source tree.

The generated method catalog is the source of truth for Telegram coverage. Run the generator whenever Telegram publishes an API update.
pnpm generate
pnpm typecheck
pnpm test
pnpm build

Generated methods are available through bot.call('methodName', params) and, after generation, through the typed API exports. The low-level client remains available for newly documented methods before a release is cut.
